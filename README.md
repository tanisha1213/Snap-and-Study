# 🎓 Snap & Study — AI Vision Study Assistant

Snap & Study is an intelligent, multimodal AI study companion designed to help students master complex academic concepts, solve homework problems, parse handwritten notes, and convert study sessions into downloadable and emailable Revision Summaries.

Built with **Python**, **Streamlit**, **Google Gemini (`google-genai`)**, and **Gmail SMTP**, Snap & Study allows students to ask questions via text or upload photos of textbook pages, mathematical equations, handwritten diagrams, code snippets, or question papers.

---

## ✨ Features

- **🧑‍🎓 Student Onboarding**: Collects student name and email using Streamlit session state for session-level personalization.
- **📸 Multimodal Vision Input**: Supports image uploads (`.jpg`, `.jpeg`, `.png`) alongside text questions to analyze handwritten notes, diagrams, math problems, and textbook questions.
- **🧠 Persistent Gemini Chat Session**: Keeps context across multi-turn study conversations (e.g. asking for follow-up explanations or alternative examples).
- **💡 Educational Guidance**: Steers explanations toward conceptual understanding and step-by-step logic instead of just giving bare answers.
- **🔎 Unclear Image Guardrails**: Gracefully identifies unreadable or cropped photos and prompts the user for a clearer upload without hallucinating details.
- **📌 One-Click Revision Summary**: Generates structured, exam-ready revision notes summarizing key topics, definitions, formulas, and takeaways.
- **✉️ Direct Email Dispatch**: Sends revision summaries straight to the student's email address using secure Gmail SMTP.
- **⚙️ Configurable & Secure**: Full credential protection using Streamlit secrets (`secrets.toml`), keeping API keys out of code and logs.

---

## 🛠️ Tech Stack

- **Frontend / Framework**: [Streamlit](https://streamlit.io/)
- **AI Core**: Google Gemini API via official [`google-genai`](https://pypi.org/project/google-genai/) SDK (`gemini-2.5-flash`)
- **Action Tool**: Python `smtplib` + `email.mime` (Gmail SMTP SSL over Port 465)
- **Language**: Python 3.9+

## 📋 Prerequisites

Before running or deploying the application, ensure you have:

1. **Python 3.9 or newer** installed on your system.
2. A **Google Gemini API Key** (Free from [Google AI Studio](https://aistudio.google.com/)).
3. A **Gmail Account** with 2-Step Verification enabled and an **App Password** created.

---

## 🔑 Setup & API Keys

### 1. Gemini API Key Setup
1. Go to [Google AI Studio](https://aistudio.google.com/).
2. Log in with your Google account.
3. Click **Get API key** -> **Create API key**.
4. Copy your generated key string.

### 2. Gmail App Password Setup
1. Go to your [Google Account Security Settings](https://myaccount.google.com/security).
2. Ensure **2-Step Verification** is turned **ON**.
3. Go to [App passwords](https://myaccount.google.com/apppasswords).
4. Create a new App Password (name it e.g. `Snap-and-Study`).
5. Copy the 16-character passcode generated by Google (without spaces).

### 3. Streamlit Secrets Setup
Create a `.streamlit/secrets.toml` file inside your project root directory by copying the example template:

```bash
# Windows PowerShell
copy .streamlit\secrets.toml.example .streamlit\secrets.toml

# macOS / Linux
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
```

Open `.streamlit/secrets.toml` and fill in your real credentials:

```toml
GEMINI_API_KEY = "AIzaSyYourActualGeminiApiKey"
GMAIL_ADDRESS = "yourstudentemail@gmail.com"
GMAIL_APP_PASSWORD = "abcd efgh ijkl mnop"
```

> ⚠️ **CRITICAL SECURITY NOTE**: Never commit `.streamlit/secrets.toml` to GitHub! It is listed in `.gitignore` by default.

## 💻 Local Installation & Running

### 1. Clone or Download Project
```bash
git clone https://github.com/your-username/Snap-and-Study.git
cd Snap-and-Study
```

### 2. Create Virtual Environment
```bash
# Windows
python -m venv venv
.\venv\Scripts\Activate.ps1

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run Application
```bash
streamlit run app.py
```

The application will launch in your web browser at `http://localhost:8501`.

## 🧪 Testing the Application Flow

Follow these steps to test every feature end-to-end:

1. **Onboarding**: Enter your name (e.g. `Alex`) and email address, then click **Start Studying**.
2. **Text Question**: Type a conceptual question (e.g. *"Explain Newton's Second Law of Motion with an example"*) into the chat input.
3. **Image Question**: Upload an image (`.jpg`, `.jpeg`, `.png`) of handwritten notes, a textbook math equation, or a diagram.
4. **Follow-up Interaction**: Ask a follow-up question (e.g. *"Can you give me a practice problem on this topic?"*) to test chat session memory.
5. **Generate Summary**: Click **Generate Revision Summary** in the top action toolbar. Verify that a structured markdown summary sheet is rendered below.
6. **Send Email**: Click **Send to Email** under the Revision Summary card. Check your email inbox for the revision notes.
7. **Reset Session**: Click **Start New Study Session** in the sidebar to verify session clearance.

## 🚀 GitHub & Deployment Instructions

### 1. Push Code to GitHub
```bash
git init
git add .
git commit -m "Initial commit of Snap & Study AI assistant"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/Snap-and-Study.git
git push -u origin main
```

*(Ensure `.streamlit/secrets.toml` is NOT pushed to GitHub).*

### 2. Deploy to Streamlit Community Cloud
1. Sign in to [Streamlit Community Cloud](https://share.streamlit.io/).
2. Click **New app**.
3. Select your GitHub repository (`Snap-and-Study`), main branch, and set Main file path to `app.py`.
4. Click **Advanced settings...** -> **Secrets**.
5. Paste your secrets configuration directly into the text box:
   ```toml
   GEMINI_API_KEY = "your_actual_key"
   GMAIL_ADDRESS = "your_actual_gmail"
   GMAIL_APP_PASSWORD = "your_16_char_app_password"
   ```
6. Click **Deploy!**.

## ⚠️ Known Limitations

1. **Gmail Rate Limits**: Gmail SMTP imposes standard sending quotas (approx. 500 emails/day for standard Gmail accounts).
2. **Image Resolution**: Highly blurry or low-light handwritten notes may require uploading a cleaner image or adding a short text hint in the chat.
3. **Gemini API Limits**: Free-tier Gemini API keys are subject to standard rate limits (requests per minute).
